# OpenShift CI/CD Final Project

## Project name
OpenShift CI/CD Pipeline Demo

## Overview
This project demonstrates a basic CI/CD workflow for a Python Flask application using GitHub Actions, pytest/nose-style unit testing, Tekton tasks, and OpenShift Pipelines.

## Project structure
- `.github/workflows/workflow.yml` — GitHub Actions lint and unit-test workflow
- `.tekton/tasks.yml` — Tekton cleanup and test tasks
- `app.py` — sample Flask application
- `tests/test_app.py` — basic unit tests
- `requirements.txt` — Python dependencies

## Run locally
```bash
python -m pip install -r requirements.txt
python -m pytest -q
```

This is a starter scaffold. Before submitting, adapt it to the exact course-provided sample application and OpenShift cluster instructions.
